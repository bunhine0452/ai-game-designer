# Sources

Full bibliography for **claude-game-designer**. Every reference file in `skills/*/references/` cites
entries from this list by ID (e.g. `[A5]`). Trust levels:

- **P** — primary: the book, paper, talk, official document, or the designer's own writing.
- **S** — secondary: reputable coverage or summaries of a primary source (trade press, conference recaps).
- **L** — low-trust: wikis, fan analysis, forum posts. Used only to locate primary sources or for
  numbers that the developer never published; always flagged in the text.

Accessed October 2026. URLs for GDC Vault sessions point to the session page; some recordings are
members-only, and many are mirrored free on the official GDC YouTube channel.
