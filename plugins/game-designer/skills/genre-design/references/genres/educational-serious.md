# Educational and serious games

Games with a purpose beyond entertainment: learning (K-12, adult skills), health and
behavior change, training and simulation, persuasion and advocacy, and citizen science.

## Core loop
Encounter a problem that needs the target knowledge or skill → act using it → feedback that
shows whether the understanding was correct → adjust → master it → apply it in harder or
transfer contexts.

## Signature mechanics
- **Intrinsic integration:** the learning content *is* the core mechanic, not a quiz between
  levels. Habgood & Ainsworth found that an intrinsically integrated math game produced
  better learning in fixed time, and that children chose to play it about seven times longer
  than an extrinsic version.
- Scaffolding and fading hints.
- Formative feedback: explain *why* an action failed.
- Learning analytics and teacher dashboards (classroom games).
- Procedural rhetoric (Bogost): systems that argue a point through their rules.

## Pacing shape
Pace by learning objectives: introduce → practice → vary → assess → transfer. Use
kishōtenketsu-style mechanic arcs for each concept. Session length is often fixed by context
(a 30–45 minute class period, a 5-minute daily habit).

## Progression model
Skill mastery mapped to curriculum objectives; adaptive difficulty from performance;
portfolios or badges only when they signal real competence.

## Balancing levers
- Challenge relative to the learner's current level (flow channel).
- Hint strength and timing.
- Ratio of practice to new content.
- Feedback detail.
- Time on task vs. the time budget available.

## Failure modes
- **"Chocolate-covered broccoli":** a game shell around unchanged drill content. Habgood &
  Ainsworth's work argues against this extrinsic approach.
- **Learning objectives that don't match mechanics**: players master the game, not the
  subject.
- **Assessment that interrupts flow.**
- **No transfer:** the skill stays inside the game. Design bridging activities.
- **Ignoring the deployment context** (classroom time, devices, teacher workload).

## Reference games (and why they work)
| Game | Why it works |
|---|---|
| DragonBox Algebra | Algebra rules introduced as game rules, with notation gradually replacing pictures (intrinsic integration) |
| Foldit | Protein folding as a puzzle; players' solutions contributed to real research |
| Zombies, Run! | Narrative motivation for a real behavior (running) |
| Kerbal Space Program | Orbital mechanics learned through failure in a sandbox |

## Design questions
1. Is the learning objective the core verb, or a gate between the fun parts?
2. How does the player find out *why* they were wrong?
3. What shows that learning transfers outside the game?
4. Who deploys it (teacher, clinician, the player), and what constraints do they have?
