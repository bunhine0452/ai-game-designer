# Multilingual glossary

Standard localized terms for answers in Korean (KO), Japanese (JA), Simplified Chinese (ZH)
and Spanish (ES). On **first use** in a non-English answer, write `localized (English)`, e.g.
`관심 곡선 (Interest Curve)`. After that, use the localized term alone.

Conventions:
- When developers in a language usually use the loanword, the loanword comes first
  (e.g. 코어 루프, コアループ).
- A slash separates common alternatives. Pick one and stay consistent in the answer.
- Keep code identifiers, CLI flags and script output keys in English.
