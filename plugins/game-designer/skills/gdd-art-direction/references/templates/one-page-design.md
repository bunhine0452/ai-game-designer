# One-page design template

Fill every field with a decision, or `OPEN QUESTION:` plus options and a recommendation.
Keep it to one screen or page. Use a diagram for the loop.

```
# <Working title> — one-page design            Owner: ___  Updated: YYYY-MM-DD  Status: draft

## In one sentence
<Fantasy: what the player gets to be or do, and why it's exciting>

| Genre | Platform / input | Session | Audience | Stage | Team / timeline |
|---|---|---|---|---|---|
|   |   |   |   |   |   |

## Target aesthetics (ranked)
1. ___  2. ___  3. ___

## Pillars
| Pillar | Test question | Rejects (example) |
|---|---|---|
|   |   |   |

## Core loops
[moment-to-moment]  verb → feedback → reward → reinvest
[session]           goal → challenge → reward → choice → new goal
[meta]              long-term progression / collection / mastery

<ASCII or Mermaid loop diagram>

## Key features (max 6, each tied to a pillar)
- Feature — pillar — why it matters

## Pacing sketch
Session: hook @ __ · peaks @ __ · climax @ __   (see fun-curve)

## Progression and economy (one line each)
Progression: ___   Currencies: ___   Monetization: ___ (ethics check: ___)

## Visual and audio target
3 reference images (what to take from each) · palette note · audio pillar

## Reference games (lesson, not feature)
- Game — the one lesson

## Risks and cheapest tests
1. ___ → test: ___ (pass if ___)
2. ___
3. ___

## Open questions
- ___ (options: A / B; recommendation: A; decide by: date)
```

Sources: [D1] Librande (2010), *One-Page Designs*. Full bibliography: `research/SOURCES.md`.
