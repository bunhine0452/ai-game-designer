# 몬스터 팜 (가제) — 원페이지 기획서 (One-Page Design)

`담당: 1인 개발자 · 갱신: 2026-10-30 · 상태: 초안 (draft)` · 근거: `01_design_brief.md`, `02_fun_curve_analysis.md`

## 한 문장

버려진 계곡 농장에서, **저마다 특기가 다른 몬스터들과 한 식구가 되어** 메마른 땅을 다시 살려 낸다.
몬스터는 일꾼이 아니라 동료이고, 그 동료가 농장의 모양을 바꾼다.

| 장르 | 플랫폼 / 입력 | 세션 | 대상 | 단계 | 팀 / 기간 |
|---|---|---|---|---|---|
| 농장 시뮬 × 몬스터 교감 (힐링) | PC(Steam), 키보드·마우스 + 게임패드 | 하루 15분, 보통 2~3일(30~45분) | 스타듀 밸리·슬라임 랜처류 힐링 게임 플레이어 | 컨셉 | 1인 / 12개월 |

## 목표 미학 (Target Aesthetics, 순위)

1. 소일거리 (Submission) 2. 발견 (Discovery) 3. 판타지 (Fantasy) — *표현 (Expression, 꾸미기)은 범위 때문에 출시 후로 미룸*

## 디자인 기둥 (Design Pillars)

| 기둥 | 판별 질문 | 거절하는 것 (예) |
|---|---|---|
| 몬스터 하나가 농장을 바꾼다 | 지형·작물·동선 중 하나라도 바꾸나요? | 능력치만 다른 "색만 바꾼" 몬스터 |
| 실패는 없고 우회만 있다 | 실수나 하루 빠짐으로 무언가를 잃나요? | 작물 고사, 기절 벌금, 미접속 시 호감도 감소 |
| 눈으로 보고 알아낸다 | 툴팁·위키 없이 화면 단서로 배울 수 있나요? | 표로만 알려 주는 조합, 숨은 확률 |

## 코어 루프 (Core Loop)

```
 [순간순간 2~10초]  몬스터에게 일 맡기기 → 땅이 바로 변함 → 하트·작은 수확 → 다음 칸
          │
          ▼
 [하루 15분]  밤사이 변화 확인 → 작업 배치·조합 → 숲·마을(재료, 의뢰, 야생 몬스터)
              → 수확·납품 → 저녁 출하 정산 + 교감 장면 → 내일 예고 ─┐
          ▲                                                          │
          └──────────── 새 조합을 해 볼 이유 ◀──────────────────────────┘
          │
          ▼
 [메타 몇 주]  변이 작물 교배 → 계곡 복원 지도(5구역) → 새 몬스터가 찾아옴 → 새 조합
```

## 핵심 기능 (최대 6개, 각각 기둥에 연결)

| 기능 | 기둥 | 왜 필요한가 |
|---|---|---|
| 몬스터 작업 배치 + 조합 효과 (8종, 조합 28쌍) | 농장을 바꾼다 | 몬스터가 "자동 스프링클러"가 되지 않게, 매일 고를 거리를 만든다 |
| 밤사이 이벤트 (변이 싹, 발자국, 몬스터가 옮긴 물건) | 보고 알아낸다 | 하루의 갈고리 (Hook) — 첫 1.5분 안에 궁금증 |
| 야생 몬스터 친해지기 (먹이·흔적 조건, **확률 없음**) | 농장을 바꾼다, 보고 알아낸다 | 하루 중간 정점. 뽑기 없이 조건을 알아내면 반드시 성공 |
| 변이 작물 교배 (인접 배치 + 몬스터 효과로 결정) | 보고 알아낸다 | 발견 미학의 장기 목표, 저녁 정산의 클라이맥스 재료 |
| 저녁 출하 정산 + 호감도 단계 연출 | 실패 없음 | 하루의 정점을 끝 쪽에 고정. 보상만 있고 손실 없음 |
| 벌칙 없는 시계와 작물 (실내·대화 중 시간 정지, 물 안 주면 성장만 멈춤) | 실패 없음 | 실시간 압박이 소일거리 미학을 깨지 않게 |

## 페이싱 스케치 (Pacing Sketch, 하루 15분)

갈고리 0.4분(밤사이 변화, 6) · 중간 정점 6.3분(야생 몬스터 친해지기, 7) · **정점 12.8분 = 85%**
(출하 정산 + 변이 판정, 8) · 예고로 끝맺음. 페이싱 건강도 29 → 92 (자세한 내용: `02_fun_curve_analysis.md`).

## 성장과 경제 (Progression & Economy)

- **성장:** 계곡 5구역 복원(의뢰·변이 작물 납품으로) → 구역마다 새 몬스터 1~2종과 작물이 찾아옴. 1년(4계절 × 10일 ≈ 10시간)에 본편 완료, 이후 자유 플레이.
- **재화:** 골드 1종(작물 판매 → 씨앗·먹이·도구). 몬스터별 호감도는 쓰는 재화가 아니라 관계 지표.
- **수익 모델:** 유료 단품. **윤리 점검:** 뽑기·확률형 아이템 없음, 출석 보상·시간 한정 이벤트 없음, 미접속 벌칙 없음. 소일거리 장르에서 흔한 "하루라도 빠지면 손해"형 다크 패턴 (Dark Pattern)을 기둥 2로 원천 차단.
- OPEN QUESTION: 골드 유입(판매)과 소모(씨앗·먹이) 수치 → `balance-economy`로 모델링 (권장: 버티컬 슬라이스 전에)

## 비주얼·오디오 목표

- **비주얼 기둥 1 — 동그란 건 친구:** 몬스터와 상호작용 오브젝트는 둥근 형태, 위험 요소는 없음(뾰족한 형태 언어 미사용).
- **비주얼 기둥 2 — 능력이 실루엣에 보인다:** 실루엣 테스트 (Silhouette Test)로 8종 모두 검은 그림자만으로 구분되고, 할 일이 형태로 읽혀야 함(물방울형 = 물, 큰 앞발 = 밭갈기).
- **비주얼 기둥 3 — 몬스터와 땅이 주인공:** 배경은 채도·명도 대비를 낮게, 몬스터와 변하는 땅(젖은 흙, 비옥한 칸)은 높게. 계절마다 색 대본 (Color Script)으로 팔레트를 바꿈.
- **오디오 기둥 — 농장이 숨 쉬는 소리:** 몬스터마다 고유 작업음이 있어 눈을 돌리지 않아도 누가 어디서 일하는지 들림. 음악은 시간대별 레이어. 모든 소리 신호에 시각 신호를 짝지음.
- **참고 이미지 방향 (원본을 베끼지 않고 배울 점만):** 수채화풍 그림책(부드러운 경계와 따뜻한 빛) · 미니어처 디오라마 사진(한 화면에 담긴 작은 세계) · 해 질 녘 시골 밭 사진(정점이 놓일 저녁의 색)

## 참고 게임 (기능이 아니라 교훈)

- **Stardew Valley** — 하루 단위가 곧 세션 구조. 출하 정산과 아침의 변화가 "하루만 더"를 만든다.
- **Slime Rancher** — 생물마다 읽기 쉬운 규칙이 있으면 규칙끼리 섞이며 플레이어가 퍼즐을 만든다.
- **Spiritfarer** — 동료의 개인적 부탁이 하루 목표와 감정적 정점을 동시에 만든다.
- **Ooblets** — 같은 조합의 선례. 반복 작업이 커지면 힐링이 노동이 된다는 경고로 읽는다.

## 위험과 가장 싼 검증

1. **몬스터가 자동 스프링클러처럼 느껴짐** → 2주 그레이박스 (Greybox, 밭 6×6, 몬스터 3종, 3일치), 테스터 5명 → *통과: 3명 이상이 2일차에 지시 없이 배치를 바꾸고, 좋아하는 몬스터 이름을 말함*
2. **범위 초과** → 버티컬 슬라이스에서 몬스터 1종·작물 1종·맵 1장을 처음부터 끝까지 만들고 시간 측정 → *통과: 몬스터 1종 ≤ 20시간. 넘으면 아래 컷 후보 실행*
3. **힐링 농장 게임 시장에서 묻힘** → "몬스터가 땅을 바꾸는 순간" 15~30초 GIF를 두 채널에 게시 → *통과: 평소 게시물 대비 반응 2배 이상(내 판단 기준)*

## 범위 점검 (Scope Check)

용량: 1인 × 집중 작업 주 27시간 × 50주 ≈ **1,350시간**, 계획 목표 ≤ 80%(1,080시간). 단가는 **자리표시 추정치**이며 M3~4 버티컬 슬라이스 실측으로 교체합니다. 연동 계수 ×1.2 적용.

| 항목 | 단가(h) | 초안 수량 | 초안(h) | 출시 수량 | 출시(h) |
|---|---|---|---|---|---|
| 몬스터 (디자인 + 애니 5종 + 행동) | 20 | 12 | 240 | **8** | 160 |
| 작물 (성장 4단계 + 데이터) | 3 | 30 | 90 | **16** | 48 |
| 맵 (농장·숲·마을) | 45 | 4 | 180 | **3** | 135 |
| 주민 (초상화 + 대사 + 의뢰) | 18 | 6 | 108 | **4** | 72 |
| 코어 시스템 (농사, 몬스터 작업·조합, 시간, 인벤토리, 상점, 의뢰, 밤사이 이벤트, 저장) | — | 꾸미기 포함 | 330 | **꾸미기 제외** | 280 |
| UI·온보딩·설정·접근성 | — | | 80 | | 80 |
| 오디오 (라이선스 음원 + 효과음 연동) | — | | 50 | | 50 |
| 마케팅 (스팀 페이지, 트레일러, 캡슐 이미지) | — | | 70 | | 70 |
| **합계 × 1.2** | | | **1,378h (102%)** | | **1,074h (80%)** |

**판단:** 출시 범위는 80% 선에 겨우 맞습니다. 사전 제작 단계의 불확실성 버퍼(+25%)까지 넣으면 약 1,343시간(99%)이라 **여유가 없습니다.**
- 대응 1: 환경 타일은 라이선스 에셋팩을 고쳐 쓰고, 몬스터는 직접 그림(기둥이므로). 맵 135h → 약 70h로 예상.
- 대응 2: M4 실측이 추정보다 크면 이 순서로 자름 — 주민 4→3 (−22h) → 작물 16→12 (−14h) → 몬스터 8→6 (−48h, 조합 28→15쌍).

## 접근성 (Accessibility) 기본 항목

- [ ] 키 재배치 (게임패드 포함), 연타·동시 입력 없음 (누르고 있기 ↔ 토글 선택)
- [ ] 글자 크기 조절, UI 글자 대비 4.5:1 이상
- [ ] 색만으로 정보 전달 금지 — 작물 상태·몬스터 기분은 색 + 아이콘
- [ ] 화면 흔들림·번쩍임 끄기
- [ ] 소리 신호(몬스터 작업음)마다 시각 신호 병행
- [ ] 시계 속도 조절·정지 옵션 (진행 속도)
