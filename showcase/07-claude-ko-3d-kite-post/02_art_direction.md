# 「종이연 우편부」 3D 아트 디렉션

## 1. 스타일: "접힌 종이 로우폴리"

- **로우폴리 + 플랫 셰이딩 + 종이 질감 한 장.** 모든 표면은 접힌 종이처럼 각진 면. 텍스처 대신 버텍스 컬러, 공용 종이 결 노멀/러프니스 1장(512px)을 전역에 타일링.
- **셰이딩**: `MeshLambertMaterial` 또는 커스텀 툰 램프(3단). 실시간 그림자는 플레이어 연 1개만(블롭 섀도 or 512px 섀도맵). 섬 그림자는 베이크(버텍스 컬러 AO).
- **형태 언어**
  - 플레이어·주민·우체국: **둥글고 삼각형 위주**(친근함). 연은 마름모 + 긴 리본 꼬리 → 실루엣만으로 진행 방향이 읽힘.
  - 섬: 아래가 뾰족한 역원뿔(떠 있음을 강조), 윗면은 평평한 착지 면.
  - 위험(폭풍 전선): **톱니·각진 사선**, 채도 낮은 보라-회색.
- **색 스크립트(시간 = 진행)**: 배달 1~3 아침(민트·크림) → 4~6 한낮(하늘색·주황 지붕) → 7 폭풍(남보라·회색) → 8 노을(주황·분홍 → 금색). 하늘 색 변화만으로 "얼마나 왔는지"가 느껴지게.
- **바람 시각화(기둥 ②)**: 상승기류 = 위로 나선 회전하는 종이 조각/민들레 씨 파티클 + 반투명 원기둥 셰이더(아래 밝고 위로 사라짐). 세기는 **파티클 속도와 색**으로 구분(약=흰색, 중=하늘색, 강=금색). 색만으로 구분하지 않도록 세기별 파티클 모양도 다르게(점/마름모/별) — 색각 이상 대응.

## 2. 웹 기준 예산

목표: **중급 노트북 내장 GPU에서 60fps, 모바일(최근 3년 중급기)에서 30fps 이상.**

| 항목 | 예산 | 비고 |
|---|---|---|
| 초기 다운로드 | **≤ 8 MB** (gzip/br 후) | 오디오 포함. 첫 화면까지 ≤ 3 MB, 나머지 지연 로딩 |
| 화면 내 삼각형 | ≤ 150k (데스크톱) / ≤ 60k (모바일) | |
| 드로우 콜 | ≤ 100 (데스크톱) / ≤ 50 (모바일) | 섬 소품은 `InstancedMesh`, 섬별 지오메트리 병합 |
| 플레이어 연 | ≤ 1.5k tris, 리본 꼬리는 본 8개 or 버텍스 셰이더 |
| 섬 1개(소품 포함) | ≤ 8k tris | 총 섬 10개 내외 |
| 주민 캐릭터 | ≤ 1.2k tris, 애니메이션 2개(대기, 기뻐함) | 1인 개발 범위 보호 |
| 텍스처 | 총 ≤ 4장, 각 ≤ 1024px, KTX2(Basis) | 대부분 버텍스 컬러 |
| 메시 포맷 | glTF + Draco/Meshopt | |
| 파티클 | 동시 ≤ 3,000 (GPU 포인트) | 화면 밖 기류는 파티클 정지 |
| 라이트 | 방향광 1 + 반구광 1 | 동적 포인트 라이트 없음 |
| 후처리 | 안개(무료) + 선택적 FXAA. 블룸은 데스크톱 옵션 | |
| 픽셀 비율 | `min(devicePixelRatio, 1.5)` (모바일 1.0) | 가장 싸고 큰 성능 레버 |

**거리 처리**: 지수 안개(`FogExp2`)로 600 m 이후를 하늘색으로 녹임 → 먼 섬은 LOD1(≤1k tris) 실루엣. 랜드마크 3개는 안개를 무시하는 별도 머티리얼로 항상 보이게(아래 §5).

## 3. 플레이어 수치 (그레이박스 초기값)

단위: m, 초. 연의 몸길이 ≈ 1.2 m, 주민 키 ≈ 1.0 m 기준.

| 수치 | 값 | 의도 |
|---|---|---|
| 순항 속도 | **14 m/s** | 섬 하나(지름 40 m)를 3초에 지나감 — 빠르지만 읽을 수 있음 |
| 최저 속도(실속 경계) | 8 m/s | 이하로 떨어지면 기수 자동 하강 + 리본이 축 늘어짐(경고) |
| 다이브 최고 속도 | 24 m/s | 다이브 시 FOV 확장으로 속도감 |
| **활공비 (순항)** | **6 : 1** (침하 ≈ 2.3 m/s) | 고도 40 m = 수평 240 m. 종이연답게 관대하게 |
| 활공비 (다이브) | 4 : 1 | 빠르지만 고도를 빨리 씀 → 위험-보상 |
| 선회율 | 최대 70°/s, 뱅크 35° | 지름 ≈ 23 m 원 선회 가능 → 기류 원기둥(지름 16~24 m) 안에서 돌 수 있어야 함 |
| 시작/기본 고도 | 섬 착지면 +40 m 발사대에서 출발 | 처음엔 60 m였으나 배달 검사에서 세션이 16분으로 늘어나 낮춤 (`03_deliveries.md`) |
| **상승기류 — 약** | 상승 4 m/s (순 +1.7 m/s), 지름 24 m | 튜토리얼용, 실패 불가 |
| **상승기류 — 중** | 상승 6 m/s (순 +3.7 m/s), 지름 20 m | 기본 |
| **상승기류 — 강** | 상승 9 m/s (순 +6.7 m/s), 지름 16 m | 좁아서 선회 실력 필요 |
| 기류 상한 | 기류 지점 위 +40 m 에서 상승 0 으로 감쇠 | 한 기류 = 최대 40 m = 수평 240 m 추가 |
| 기류 1회 상승 시간 | 중 기준 ≈ 11 초 | 배달 목표 시간 계산에 사용(`scripts/check_deliveries.py`) |
| 바람길(수평 기류) | 등 뒤 +6 m/s, 역풍 −4 m/s | 7번 배달 이후에만 등장 |
| 추락 재시작 | 3 초 | 처벌보다 리듬 유지 |

**튜닝 원칙**: 그레이박스 테스트에서 "첫 기류 선회 성공률"이 낮으면 선회율보다 **기류 지름을 먼저 키운다**(조작감은 유지, 난이도만 낮춤).

## 4. 카메라 규칙

1. **3인칭 추적, 연 뒤 8 m · 위 2.5 m**, 연을 화면 하단 1/3 지점에 배치 → 진행 방향 하늘이 넓게 보이게.
2. **스프링 감쇠**: 위치 지연 0.25 s, 회전 지연 0.15 s. 선회 시 카메라가 연보다 살짝 늦게 돌아 원심감을 줌. **카메라 롤은 연 뱅크의 30%만** 따라감(멀미 방지). 옵션에서 0%로 끌 수 있음.
3. **FOV**: 순항 60° → 다이브 72°까지 속도 비례. 상승기류 안에서는 58°로 살짝 좁혀 "안정"을 느끼게.
4. **기류 안 선회 시**: 카메라를 3 m 뒤로 빼고 4 m 위로 올려 기류 원기둥 전체와 다음 목적지가 동시에 보이게 (기류 상단 감쇠 구간에서 다음 방향을 미리 고르게 하기 위함).
5. **충돌**: 카메라와 연 사이에 지형이 끼면 카메라를 당겨서 연을 절대 가리지 않음. 섬 아래 통과 시에는 지형을 디더 투명 처리.
6. **착지/배달 연출**: 1.5 s 짧은 컷(받는 사람 얼굴) — 스킵 가능, 입력 즉시 복귀.
7. **절대 하지 않는 것**: 플레이어 입력 중 카메라 강제 회전, 화면 흔들림 기본 ON(폭풍 구간도 옵션으로만).
8. **고도 판단 보조**: 연 바로 아래 지면/구름바다에 원형 그림자 + 착지 예상 지점 점선(활공비로 계산). 3D 거리 판단 실패라는 브리프의 부차 위험을 직접 다룸.

## 5. 길찾기 (랜드마크)

원칙: **나침반·미니맵 없이 랜드마크만으로 길을 찾는다.** HUD에는 목적지 방향 화살표 대신 "편지에 적힌 주소(랜드마크 이름 + 그림)"만 표시. 3회 이상 헤매면(60초 이상 목적지에서 멀어짐) 종이새 한 마리가 방향을 알려주는 보조.

| 랜드마크 | 형태 | 역할 | 어디서 보이나 |
|---|---|---|---|
| **하늘 우체국** (중심) | 빨간 우체통 모양의 탑 + 꼭대기에 회전하는 풍향계 | 출발점·귀환점. 모든 경로의 기준 "북극성" | 어디서나 (안개 무시) |
| **흰 등대** (동) | 가늘고 높은 수직 실루엣, 밤에는 회전 광선 | 동쪽 군도 기준 | 400 m |
| **큰 풍차** (서) | 회전하는 날개 — 움직이는 랜드마크라 멀리서 눈에 띔 | 서쪽 군도 기준 | 400 m |
| **폭포섬** (남) | 섬 가장자리에서 아래 구름바다로 떨어지는 하얀 물줄기 | 남쪽 기준, 소리로도 방향 단서(3D 오디오) | 350 m |
| **폭풍 전선** (북) | 거대한 보라색 구름벽 | "아직 가면 안 되는 곳" → 마지막 배달 목적지 | 항상(배경) |

- **브레드크럼**: 상승기류 파티클 자체가 경로 표시. 배달 경로 위의 기류는 해당 편지 봉투 색 리본이 기류 꼭대기에 달려 있음.
- **색 규칙**: 목적지 섬 지붕 = 편지 봉투 색. 첫 배달에서 "봉투 색 = 지붕 색"을 한 번만 가르친다.
- **시선 유도**: 우체국 발사대에서 출발할 때 카메라가 목적지 랜드마크 쪽을 향한 상태로 시작.
