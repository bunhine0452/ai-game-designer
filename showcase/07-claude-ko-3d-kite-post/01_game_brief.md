# 「종이연 우편부」 게임 브리프

- 플랫폼: 브라우저(데스크톱 우선, 모바일 터치는 2순위) · three.js · 1인 개발
- 세션: 10~15분, 한 번에 끝나는 짧은 여정 (배달 8건)
- 장르: 활공/비행 탐험 + 가벼운 타임 어택 (참고: *Alto's Odyssey*의 흐름, *Pilotwings*의 상승기류, *A Short Hike*의 짧고 따뜻한 규모)

## 1. 플레이어 판타지

> "바람을 읽을 줄 아는 작은 우편부가 되어, 손편지 한 장을 들고 하늘섬 사이를 미끄러지듯 건넌다."

핵심 감정은 **스피드가 아니라 '바람과 한 몸이 되는 느낌'**이다. 고도는 곧 자원이고, 상승기류는 하늘의 주유소다.
편지를 받은 주민의 짧은 반응(한 줄 대사 + 작은 애니메이션)이 "누군가에게 닿았다"는 따뜻함을 준다.

## 2. 디자인 기둥 3개

| 기둥 | 의미 | 이 기둥으로 거절하는 것 |
|---|---|---|
| **① 고도는 숨이다** | 모든 결정은 "지금 고도를 쓸까, 아낄까"로 수렴한다. 연료·스태미나 게이지 없음 — 고도 하나만 자원. | 부스트 아이템, 연료 게이지, 무한 비행 |
| **② 바람은 보인다** | 상승기류·바람길은 반드시 눈에 보인다(종이 조각, 민들레 씨, 연기, 깃발). 운이 아니라 읽기의 게임. | 보이지 않는 함정 기류, 무작위 돌풍 |
| **③ 한 장의 편지, 한 사람의 얼굴** | 배달마다 받는 사람과 짧은 사연이 있다. 15분 안에 작은 이야기가 닫힌다. | 대량 배달, 경제 시스템, 인벤토리 |

## 3. 코어 루프

```
 ┌─ 30초 루프 (조작) ─────────────────────────────────┐
 │  활공(고도 소모) → 기류 발견 → 선회 상승(고도 회복) → 다음 섬 방향 결정 │
 └──────────────────────────────────────────────────┘
 ┌─ 1~2분 루프 (배달) ───────────────────────────────┐
 │  우체국에서 편지 수령 → 랜드마크 보고 경로 계획 → 비행 → 착지/투하       │
 │  → 받는 사람 반응 + 우표 보상 → 다음 편지                              │
 └──────────────────────────────────────────────────┘
 ┌─ 15분 루프 (여정) ─────────────────────────────────┐
 │  우표로 연 꼬리/무늬 해금(외형만) → 하늘섬 지도가 하나씩 밝아짐            │
 │  → 마지막 편지: 폭풍을 뚫고 '하늘 우체국'으로                           │
 └──────────────────────────────────────────────────┘
```

- 실패 규칙: 바다(구름바다)로 떨어지면 **마지막 섬에서 3초 내 재시작**, 편지는 젖지 않는다. 시간 초과는 실패가 아니라 보상 감소(금·은·동 우표).
- 조작: 마우스/WASD로 좌우 선회·피치(기수 내리면 가속·고도 소모, 올리면 감속·실속 위험). 버튼 하나로 "편지 투하".

## 4. 가장 큰 위험

**"활공 조작감이 15분 내내 재미있는가"** — 이 게임의 재미 전부가 비행 느낌 하나에 걸려 있다.
조작이 둔하면 지루하고, 예민하면 멀미·좌절이 온다. 섬·스토리·보상은 비행이 재미없으면 아무것도 구하지 못한다.

부차 위험: (a) 3D 공간에서 거리·고도 판단이 어려워 "닿을 줄 알았는데 못 닿음"의 억울함, (b) 1인 개발 범위 폭주(섬 개수, 캐릭터 애니메이션).

## 5. 가장 싼 검증 방법 (2~3일)

**그레이박스 비행 테스트**: three.js 기본 도형만으로.

1. 박스 섬 3개 + 원기둥 상승기류 3개 + 종이연 = 납작한 삼각형 하나. 아트 0.
2. 수치는 `02_art_direction.md` §3의 플레이어 수치를 그대로 상수로 넣고, 디버그 슬라이더(lil-gui)로 활공비·선회율·기류 세기를 실시간 조정.
3. 지인 5명에게 "A섬에서 C섬까지 편지 1장"만 시키고 관찰.

**통과 기준**
- 5명 중 4명이 설명 없이 3분 안에 첫 상승기류 선회에 성공
- 테스트 후 "한 번 더"를 자발적으로 요청한 사람 ≥ 3명
- 추락 후 "억울하다"(거리 판단 실패) 발언 ≤ 1명 → 넘으면 착지 예측선/그림자 표시부터 추가

이 기준을 통과하기 전에는 섬 아트·대사·보상 시스템에 손대지 않는다.
