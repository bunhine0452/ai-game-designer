## 핵심 결론

1. **이 게임은 비행 조작감이 전부다.** 가장 큰 위험은 "활공이 15분 내내 재미있는가"이다. 아트나 이야기를 만들기 전에 2~3일짜리 그레이박스 테스트(박스 섬 3개 + 원기둥 기류 3개 + 디버그 슬라이더, 5명)로 검증한다. 통과 기준: 4/5명이 3분 안에 첫 기류 선회에 성공하고, 3명 이상이 "한 번 더"를 요청한다.
2. **기둥**: ① 고도는 숨이다(자원은 고도 하나) ② 바람은 보인다(운이 아니라 읽기) ③ 한 장의 편지, 한 사람의 얼굴(배달할 때의 반응이 이야기이자 페이싱의 이완 장치).
3. **핵심 수치**: 순항 14 m/s, 활공비 6:1, 출발 고도 40 m, 기류 약/중/강 = 상승 4/6/9 m/s(순 +1.7/+3.7/+6.7), 기류당 최대 +40 m. 웹 예산은 첫 화면까지 3 MB 이하, 전체 8 MB 이하, 드로우콜 100 이하, 픽셀 비율 1.5 이하.
4. **배달 테이블**: 초안을 최종 수치로 검사하면 **14건**이 나온다(v1 수치로는 12건). 완벽하게 날아도 못 맞추는 목표 시간 4건, 난이도 톱니, 보상 역전, 세션 16분. 출발 고도를 60 → 40 m로 낮추고, 필수 기류를 1·1·1·2·2·3·3·4 계단으로, 목표 시간을 최적 시간 ×1.16~1.42로 역산해 **문제 0건, 세션 14.4분**이 됐다. 난이도는 1.76 → 6.03까지 한 단계 ×1.6 이하로 계속 오르고, 난이도당 보상도 5.7 → 8.3으로 계속 오른다.
5. **관심 곡선**: 초안은 **건강도 38/100**이었다. 후킹 없이 텍스트 튜토리얼로 시작하고, 3~8분이 평탄하고, 마지막 2.5분 동안 고강도가 끊기지 않는 "계속 오르기만 하는 비탈"이었다. 오프닝 15초 다이브, 배달마다 다른 종류의 피크, 배달 반응을 이완으로 사용, 7:35 휴식, 폭풍의 눈 → 최종 다이브 → 반전 엔딩으로 고쳐 **100/100**이 됐다. 피크는 7→7→8→8→9→9→10으로 배달 난이도 계단과 맞물린다.
6. **스크립트가 못 잡는 남은 위험**: (a) 2~7분 톱니 리듬이 너무 규칙적일 수 있다 → 지루하면 #4·#5를 연속 배달로 묶는다. (b) #4의 난이도 점프 ×1.58은 제한에 거의 닿는다 → 추락이 많으면 여분 기류를 1개 더 준다. (c) 바람길과 폭풍은 검사 모델에 들어 있지 않다 → #7·#8의 실제 체감 난이도는 표보다 높을 것이다. 강도와 난이도 숫자는 모두 추정이므로 플레이테스트 체감 점수로 다시 돌려 확인해야 한다.
