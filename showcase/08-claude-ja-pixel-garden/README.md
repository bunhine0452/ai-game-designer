## 主な結論
1. **ジャンルの核**: ゼルダ型の「道具を持ち歩く」お約束を破り、**能力を地面に植える**（種は部屋ごとに3つ、引き抜くと戻る）。「どこに・どの順で」がパズルの中身になり、庭師というテーマと仕組みが一致する。死ぬことはなく、アンドゥ・リセットはいつでも使える。
2. **アート**: 320×180、16pxタイル、パレットは27色（上限32）。**予約色**（主人公＝赤、ツタ＝鮮やかな緑、キノコ＝マゼンタ、ヒマワリ／光＝黄）と、**アウトラインがある物＝触れる物**というルールで画面を読みやすくする。荒廃・開花・暗闇の3状態は**パレット差し替え**で作り、作画の量を3分の1に抑える。
3. **6部屋**: R1 ツタ → R2 キノコ → R3 ヒマワリ → R4 ツタ×キノコ → R5 ひねり（光の中でしか芽吹かない）→ R6 全部と引き抜き。難易度は★1-2-2-3-4-4のノコギリ型。
4. **興味曲線**: 素朴な初稿は健全度 **43/100**（フックなし、低くて平坦な区間が5分続く、パズルが7連続）。冒頭のテキストを削って**0:24にツタのフック**を置き、部屋ごとに**開花の報酬の山**を、部屋の間に**期待を作る谷**を入れた。最高潮は **14.1分（94%）** に置いた。v3 で **100/100、指摘0件**。ただしこれは予測なので、プレイテストで確かめる。
5. **範囲**: 見積もりは約206時間＋予備30%で **約270時間**（週15時間なら約18週）。一番のリスクはパズルの品質（特にR5・R6）。最初の2週間で、R1・R4・R5 のグレーボックスを3人に遊んでもらって確かめる。
