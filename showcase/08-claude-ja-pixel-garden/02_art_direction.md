# 02 ドット絵アートディレクション（Pixel Art Direction）—「ドット庭師」

## 0. ビジュアルの柱（Visual Pillars）
1. **荒廃から開花へ** — 部屋は最初くすんだ寒色。解くと暖かく鮮やかな色が戻る。色の変化そのものがご褒美になる。
2. **触れる物だけが鮮やか** — 背景は彩度を落とし、操作できる物（主人公・植物・植えられる土）だけを高彩度にする。
3. **少ない描き込みで素材を使い回す** — 一人開発なので、手で描き分けるより**パレット差し替え（Palette Swap）**で「荒廃／開花／暗闇」の3つの見た目を作る。

---

## 1. 内部解像度（Internal Resolution）
- **320×180**（16:9）。表示は整数倍（Integer Scaling）で拡大する: ×4 = 1280×720、×6 = 1920×1080。
- 画面構成: 上の **20px を HUD 帯**に使い、残りの **320×160 をプレイ領域**にする（16pxタイルで20×10マス）。
- 部屋は1画面固定で、カメラはスクロールしない。部屋の移動は横スライド（250ms）。
- 実装: 320×180 のオフスクリーン canvas に描き、CSS `image-rendering: pixelated` で拡大する。拡大率はウィンドウに収まる最大の整数にし、余白は黒帯にする。

## 2. タイルとキャラクターのサイズ（Tile & Sprite Metrics）
| 対象 | サイズ | メモ |
|---|---|---|
| 基本タイル | **16×16** | 見下ろし3/4視点（ゼルダ風）。壁は手前の面を描いて高さを表す |
| 主人公 | **16×16 セル**（体は約11×14） | 頭身は約2.5。帽子と赤いスカーフでシルエットを作る |
| ツタ（橋） | 16×16 × 長さ（最大4） | 始点・中間・終点の3パーツ。歩ける面に横縞の模様を入れる |
| キノコ | 16×16 | 大きな丸い傘に白い斑点。傘が上下に潰れる動き（Squash & Stretch）で弾みを見せる |
| ヒマワリ | **16×32**（2マス分の高さ） | 主人公より背が高く、遠くからでも目立つ。光の半径は3マス（48px） |
| 種（HUD・地面） | 8×8 | HUD にスロットを3つ並べる |
| 影虫 | 8×8 | 丸い体に目が2つ。光に入ると逃げる |

**シルエットのテスト（Silhouette Test）**: 全部を黒一色で塗っても、ツタ（横長）・キノコ（丸い傘）・ヒマワリ（縦長と放射）・主人公（帽子）が見分けられること。**色覚多様性（Color Vision Deficiency）にも、色ではなく形で対応する**。

## 3. パレット（Palette）— 基本27色（上限32、5色を予備に残す）
環境の色は**くすんだ色のランプ（Ramp）**でまとめ、**予約色（Reserved Colors）**はゲームの意味を持つ物にしか使わない。

### 環境ランプ（荒廃状態の基準）
| ランプ | 色（暗 → 明） | 用途 |
|---|---|---|
| 石（寒色の灰紫）×5 | `#1a1726` `#3a3a52` `#5f6378` `#8b93a1` `#c3c8c9` | 遺跡の壁・床。最暗色は虚空・穴・アウトライン兼用 |
| 苔（くすんだ青緑）×4 | `#24372f` `#3d5a45` `#5f7d58` `#8ea36f` | 環境の草木。**操作できる植物より必ず暗く、彩度も低い** |
| 土 ×4 | `#3b2a26` `#6b4a3a` `#9a7050` `#c9a27a` | 植えられる土（明るい2色）・木材 |
| 水 ×3 | `#1f3b5a` `#3c6e8f` `#74a9be` | 堀・噴水 |
| 光 ×1 | `#f2ead3` | ハイライト・UI の文字・キノコの斑点 |

### 予約色（他の用途への流用は禁止）
| 意味 | 色 | ルール |
|---|---|---|
| **主人公** | `#d9483b`（スカーフ）`#8f2a32`（影）`#e8b796`（肌） | 赤は主人公にしか使わない |
| **ツタ** | `#4fd16a` `#1f8a5a` | 環境の苔とは明度と彩度ではっきり分ける |
| **キノコ** | `#e0559a` `#8c2f6e` | マゼンタは「跳べる」という意味にだけ使う |
| **ヒマワリ／光** | `#ffd23f` `#f08a24` | 黄色は「光」の意味にだけ使う。日記のページの縁取りにも使う（光の中にある物） |
| **暗闇** | `#0d0b14` | 光の外側の塗りつぶし用 |

### パレット差し替えで作る3つの状態
- **荒廃（初期）**: 上の表のまま。
- **開花（クリア後）**: 苔のランプを鮮やかな緑（`#3f7a3a`→`#b8e07a`）に、石のランプを暖色寄りに差し替える。中心から波紋状に広げる8段階のアニメーション。※ 差し替え用の色は上の27色とは別に、開花用のテーブルとして持つ。
- **暗闇（R3・R5）**: 環境の色はすべて**2段階暗い色**にずらし（対応表を1つ作る）、光の範囲外は `#0d0b14` で塗る。光の縁は2pxのディザ（Dithering）にする。**半透明は使わない**ので、色数が崩れない。

## 4. アウトラインの方針（Outline Policy）
- **主人公・操作できる植物・影虫**: 1pxの**セルアウト（Selective Outline）**。外周はそのランプの最暗色で描き、光が当たる上側だけ1段明るくする。これで背景から浮き出る。
- **環境タイル**: **アウトラインは描かない**。陰影だけで形を作る。
- **影**: 物の足元に、石ランプの最暗色で楕円（横10px×縦3px）を描く。半透明は使わない。
- 結果として「線がある物＝触れる物」というルールが自然に伝わる。

## 5. アニメーションのコマ数（Animation Frames）
ロジックは60fpsで動かし、スプライトのアニメは基本**12fps（1コマ約83ms）**にする。

| 対象 | コマ数 | 方向 | メモ |
|---|---|---|---|
| 主人公 待機 | 2 | 4方向（左右は反転で流用＝3方向分を描く） | 500msごとに呼吸 |
| 主人公 歩行 | 4 | 同上 | 1マス移動は150ms で補間 |
| 主人公 植える／抜く | 3 | 同上 | しゃがむ → 手を伸ばす → 戻る |
| 主人公 跳躍（キノコ） | 4 | 同上 | 踏み込み → 上昇 → 頂点 → 着地 |
| 主人公 落下して復帰 | 3 + 点滅 | 共通 | 罰ではないので軽く見せる |
| 主人公 喜ぶ（開花） | 2 | 正面 | |
| ツタ 成長 | 1マスごとに3コマ（60ms間隔） | 4方向（回転で流用） | 伸びていく様子がフックの見せ場 |
| キノコ 生える／弾む | 4 / 3 | — | 弾むときに傘が潰れる |
| ヒマワリ 開く／揺れる | 5 / 2 | — | 光の半径を2コマで揺らす |
| 影虫 移動／逃げる | 2 / 2 | — | |
| 開花の波紋 | 8段階 | — | パレット差し替えを段階的に広げる |

**描くスプライトの合計: 約65コマ**（主人公は約45コマ）。

## 6. UI とフォント（UI & Font）
- **HUD（上の20px帯）**: 左に種スロット3つ（8×8アイコン）、中央に部屋名（入室時に2秒だけ表示）、右にリセット／アンドゥのキー表示（小さなアイコン）。**数字やテキストは極力使わない**。
- **フォント**: 日本語の本文には **PixelMplus10**（10px、M+ FONT LICENSE で商用可）。8pxの美咲フォントは漢字が潰れやすいので見出しの英数字だけに使う。数字は自作の 4×6 ドットフォント。※ 採用前にライセンスを確認すること。
- **文字量**: 物語は日記の断片3枚のみ。1枚は最大2行×18字で、モーダルで表示し、どのキーでも閉じられる。
- **操作のヒント**: 文字で出すより、主人公の頭上にキーのアイコンを表示する。キー配置の変更（Remapping）に合わせてアイコンも差し替える。
- **アクセシビリティ（Accessibility）**: 時間制限なし／画面のフラッシュなし／色ではなく形で意味を伝える／キー配置の変更／マウスでも操作できる（クリックしたマスへ移動）／音量はBGMと効果音を別々に調整。
- **カーソル**: 植えられるマスは光ランプ `#f2ead3` の四隅のカギ（L字の角）で示す。植えられないマスは「×」で示す。
